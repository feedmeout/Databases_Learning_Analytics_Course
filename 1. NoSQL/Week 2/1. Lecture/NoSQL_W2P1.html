Η εντολή mongoimport

Εντολή, στο τερματικό

mongoimport books.json -d library -c books --drop --maintainInsertionOrder

Αποτέλεσμα

2026-10-03T03:37:16.226+0300	connected to: mongodb://localhost/
2026-10-03T03:37:16.227+0300	dropping: `library.books`
2026-10-03T03:37:16.255+0300	431 document(s) imported successfully. 0 document(s) failed to import.
  • -d library: η βάση. -c books: η συλ­λογή. Δη­μιουρ­γού­νται με την ει­σα­γωγή.
  • --drop: δια­γρά­φει πρώτα τη συλ­λογή, ώστε μια δεύ­τερη ει­σα­γωγή να μη βρει διπλά. --maintainInsertionOrder: τα έγ­γραφα μπαί­νουν με τη σειρά του αρ­χείου, την ίδια για όλους.
  • Εκτε­λεί­ται στο τερ­μα­τικό του συ­στή­μα­τος, όχι μέσα στο mongosh.

  }
]
  • sort: 1 για αύ­ξουσα, -1 για φθί­νουσα σειρά. Εδώ: τα πιο πρό­σφατα πρώτα.
  • limit(3): μόνο τα τρία πρώτα. Με limit(1): το πιο πρό­σφατο βιβλίο.
  • Ερ­γα­σία 2, ενό­τητα 9και αύ­ξουσα και φθί­νουσα

MongoDB Manual: cursor.sort(), cursor.limit().

Προσοχή

Τα μηδενικά πρώτα

Εντολή

db.books.find(
  {}, { title: 1, pageCount: 1, _id: 0 }
).sort({ pageCount: 1 }).limit(3)

Αποτέλεσμα

[
  { title: 'SOA Governance in Action', pageCount: 0 },
  { title: 'Specification by Example', pageCount: 0 },
  { title: 'MongoDB in Action', pageCount: 0 }

  • Τα «μι­κρό­τερα» βιβλία έχουν 0 σε­λί­δες: είναι τα 166 με άγνω­στο αριθμό.
  • Με $gt: 0 στο pageCount, τα τρία πρώτα έχουν 180, 200 και 200 σε­λί­δες.

Να θυμάστε

Βασικά συμπεράσματα

  1. Το find παίρ­νει δύο έγ­γραφα: το φίλτρο επι­λέ­γει έγ­γραφα, η προ­βολή επι­λέ­γει πεδία.
  2. Σε πεδίο-λίστα αρκεί να ται­ριά­ζει ένα στοι­χείο. Η λίστα σε αγκύ­λες ζητά ακρι­βώς την ίδια λίστα.
  3. Πριν από τα ερω­τή­ματα, κοι­τάξτε τα δε­δο­μένα: 0 σε­λί­δες ση­μαί­νει «άγνω­στο», και τα πεζά δια­φέ­ρουν από τα κε­φα­λαία.
