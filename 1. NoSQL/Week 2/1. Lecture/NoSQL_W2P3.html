updateOne και $set

Εντολές

use world
db.country.updateOne(
  { name: "Greece" },
  { $set: { capital: { name: "Athens", timezone: "Europe/Athens" } } }
)

Αποτελέσματα

switched to db world
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
  • Πρώτο όρισμα: το φίλτρο. Δεύ­τερο: η αλλαγή, με τε­λε­στή.
  • Το $set προ­σθέ­τει το πεδίο capital. Αν υπήρχε, θα άλλαζε την τιμή του.
  • Ερ­γα­σία 2, ενό­τητα 11: ενη­μέ­ρωση ενός εγ­γρά­φου.

MongoDB Manual: db.collection.updateOne().

4

matchedCount και modifiedCount

Η ίδια εντολή, δεύτερη φορά

db.country.updateOne(
  { name: "Greece" },
  { $set: { capital: { name: "Athens", timezone: "Europe/Athens" } } }
)

Αποτέλεσμα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 0,
  upsertedCount: 0
}
  • Βρέ­θηκε ένα έγ­γραφο (matchedCount: 1), αλλά δεν άλλαξε (modifiedCount: 0): η τιμή ήταν ήδη αυτή.
  • Με matchedCount: 0, το φίλτρο δεν βρήκε τίποτε: π.χ. "greece" με πεζό.

5

$inc και $push

Εντολές

db.country.updateOne(
  { name: "Greece" },
  { $inc: { visits: 1 }, $push: { languages: "Greek" } }
)
db.country.findOne({ name: "Greece" }, { _id: 0 })

Αποτελέσματα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
{
  name: 'Greece',
  euSince: 1981,
  population: 10400000,
  capital: { name: 'Athens', timezone: 'Europe/Athens' },
  languages: [ 'Greek' ],
  visits: 1
}
  • Η Ελλάδα δεν είχε visits: το $inc το δη­μιουρ­γεί με τιμή 1.
  • Ούτε λίστα languages είχε: το $push τη δη­μιουρ­γεί με ένα στοι­χείο.
  • Δύο τε­λε­στές στην ίδια ενη­μέ­ρωση, ένα modifiedCount: 1.

MongoDB Manual: Field and Array Update Operators.

$unset: αφαίρεση πεδίου

Εντολή

db.country.updateOne({ name: "Greece" }, { $unset: { visits: "" } })

Αποτέλεσμα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
  • Το πεδίο visits αφαι­ρεί­ται. Η τιμή μετά το όνομα δεν έχει ση­μα­σία, και συ­νή­θως γρά­φε­ται "".
  • Με update­Many, το ίδιο πεδίο αφαι­ρεί­ται από όλα τα έγ­γραφα που ται­ριά­ζουν.

updateOne: μόνο το πρώτο έγγραφο

Εντολές

db.country.updateOne({ euSince: 1958 }, { $set: { founder: true } })
db.country.countDocuments({ founder: true })
db.country.updateMany({ euSince: 1958 }, { $set: { founder: true } })

Αποτελέσματα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
1
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 2,
  modifiedCount: 1,
  upsertedCount: 0
}
  • Η Γαλλία και η Γερ­μα­νία έχουν euSince 1958, αλλά το updateOne άλλαξε μόνο την πρώτη.
  • Το update­Many βρήκε και τις δύο (matchedCount: 2) και άλλαξε όποια δεν είχε ήδη την τιμή (modifiedCount: 1).

updateMany: από «0 σελίδες» σε «άγνωστο»

Εντολές

use library
db.books.updateMany({ pageCount: 0 }, { $unset: { pageCount: "" } })
db.books.countDocuments({ pageCount: { $exists: false } })

Αποτελέσματα

switched to db library
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 166,
  modifiedCount: 166,
  upsertedCount: 0
}
166
  • Με ένα φίλτρο, το updateMany αφαι­ρεί το pageCount από τα 166 βιβλία με 0 σε­λί­δες.Το $exists: false μετρά όσα δεν έχουν πια pageCount.
  • Τώρα το «άγνω­στο» είναι πεδίο που λείπει, όχι ψεύ­τικο 0: δεν μετρά στους μέσους όρους.
  • Επα­να­φορά της συλ­λο­γής: ξανά mongoimport … --drop, μετά τη συ­νά­θροιση.

$group: ο συνολικός πληθυσμός

Εντολή

db.country.aggregate([
  { $group: { _id: null, totalPopulation: { $sum: "$population" } } }
])

Αποτέλεσμα

[ { _id: null, totalPopulation: 162600000 } ]
  • _id: null: μία μόνο ομάδα, όλα τα έγ­γραφα μαζί.
  • "$population": με το $ μπρο­στά από το όνομα, η τιμή του πεδίου population.
  • Ελλάδα, Γαλλία και Γερ­μα­νία: 162.600.000.

MongoDB Manual: $group (aggregation).

16

$match και υπολογισμοί ανά ομάδα

Εντολή

db.books.aggregate([
  { $match: { categories: "Java" } },
  { $group: { _id: "$status", books: { $sum: 1 },
              avgPages: { $avg: "$pageCount" },
              maxPages: { $max: "$pageCount" } } }
])

Αποτέλεσμα

[
  { _id: 'MEAP', books: 1, avgPages: 700, maxPages: 700 },
  {
    _id: 'PUBLISH',
    books: 95,
    avgPages: 511.4868421052632,
    maxPages: 1088
  }
]
  • $match πρώτο: μόνο τα βιβλία Java, όπως το WHERE.
  • $avg και $max: μέσος όρος και μέ­γι­στο ανά ομάδα.
  • Το $avg αγνοεί τα βιβλία που δεν έχουν πλέον pageCount.

MongoDB Manual: $avg (aggregation).

$unwind: ένα έγγραφο ανά κατηγορία

Εντολή

db.books.aggregate([
  { $unwind: "$categories" },
  { $group: { _id: "$categories", books: { $sum: 1 } } },
  { $sort: { books: -1 } },
  { $limit: 5 }
])

Αποτέλεσμα

[
  { _id: 'Java', books: 96 },
  { _id: 'Internet', books: 41 },
  { _id: 'Microsoft .NET', books: 34 },
  { _id: 'Web Development', books: 17 },
  { _id: 'Software Engineering', books: 16 }
]
  • $unwind: ένα έγ­γραφο για κάθε κα­τη­γο­ρία κάθε βι­βλίου.
  • Μετάομάδα ανά κα­τη­γο­ρία, τα­ξι­νό­μηση, τα πέντε πρώτα
  • Βιβλία χωρίς κα­τη­γο­ρία δεν περ­νούν από το $unwind.

MongoDB Manual: $unwind (aggregation).

18

$match μετά το $group: το HAVING

Εντολή

db.books.aggregate([
  { $unwind: "$categories" },
  { $group: { _id: "$categories", books: { $sum: 1 } } },
  { $match: { books: { $gte: 12 } } },
  { $sort: { books: -1, _id: 1 } }
])

Αποτέλεσμα

[
  { _id: 'Java', books: 96 },
  { _id: 'Internet', books: 41 },
  { _id: 'Microsoft .NET', books: 34 },
  { _id: 'Web Development', books: 17 },
  { _id: 'Software Engineering', books: 16 },
  { _id: 'Business', books: 12 },
  { _id: 'Programming', books: 12 }
]
  • $match μετά το $group φιλ­τρά­ρει ομάδες, όπως το HAVING της SQL.
  • Κα­τη­γο­ρίες με του­λά­χι­στον 12 βιβλία: επτά.
  • _id: 1 στο $sort: στα­θερή σειρά στις ισο­πα­λίες.

19

$project: το σχήμα της εξόδου

Εντολή

db.books.aggregate([
  { $match: { categories: "Java" } },
  { $group: { _id: "$status", books: { $sum: 1 },
              avgPages: { $avg: "$pageCount" } } },
  { $project: { _id: 0, status: "$_id", books: 1,
                avgPages: { $round: ["$avgPages", 0] } } }
])

Αποτέλεσμα

[
  { books: 1, status: 'MEAP', avgPages: 700 },
  { books: 95, status: 'PUBLISH', avgPages: 511 }
]
  • $project: ποια πεδία εμ­φα­νί­ζο­νται και με ποιο όνομα. Εδώ το _id γί­νε­ται status.
  • $round: στρογ­γυ­λο­ποί­ηση του μέσου όρου.
  • Το $project αντι­στοι­χεί στο SELECT της SQL.

MongoDB Manual: $project, $round (aggregation).
