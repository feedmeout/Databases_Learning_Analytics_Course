Ένα λυμένο παράδειγμα

SQL

SELECT title, pageCount FROM books
WHERE status = 'MEAP' AND pageCount > 0
ORDER BY pageCount DESC
LIMIT 3

MongoDB

db.books.find(
  { status: "MEAP", pageCount: { $gt: 0 } },
  { title: 1, pageCount: 1, _id: 0 }
).sort({ pageCount: -1 }).limit(3)

Αποτέλεσμα

[
  { title: 'Groovy in Action, Second Edition', pageCount: 700 },
  { title: 'F# in Action', pageCount: 425 },
  { title: 'Distributed Agile in Action', pageCount: 325 }
]
  • Το WHERE γίνεται φίλτρο, και το AND γράφεται με κόμμα.
  • Το SELECT title, pageCount γίνεται προβολή.
  • Το ORDER BY … DESC γίνεται sort με -1, και το LIMIT γίνεται limit.

AND ή OR

Εντολές

db.books.countDocuments({ categories: "Java", status: "PUBLISH" })
db.books.countDocuments({ $or: [ { categories: "Java" },
                                 { status: "PUBLISH" } ] })
db.books.countDocuments({ status: "PUBLISH" })
db.books.countDocuments({ categories: "Java", status: "MEAP" })

Αποτελέσματα

95
364
363
1
  • Ζητούμενο 5, AND: 95 βιβλία Java που κυκλοφόρησαν.
  • Ζητούμενο 6, OR: 364, δηλαδή τα 363 που κυκλοφόρησαν και ένα βιβλίο Java σε MEAP.
  • Το «είτε… είτε» της εκφώνησης είναι OR: αρκεί μία από τις δύο συνθήκες.

8

Ταξινόμηση κειμένου: τα πεζά στο τέλος

Εντολές

db.books.find(
  { categories: "Java" }, { title: 1, _id: 0 }
).sort({ title: -1 }).limit(3)
db.books.find(
  { categories: "Java" }, { title: 1, _id: 0 }
).sort({ title: -1 }).collation({ locale: "en" }).limit(3)

Αποτελέσματα

[
  { title: 'jQuery in Action, Second Edition' },
  { title: 'iText in Action, Second Edition' },
  { title: 'XML Parsing with Digester' }
]
[
  { title: 'XML Parsing with Digester' },
  { title: 'XDoclet in Action' },
  { title: 'Working with the Logging and Discovery Components' }
]
  • Η MongoDB συγκρίνει τα κείμενα χαρακτήρα προς χαρακτήρα: όλα τα κεφαλαία πριν από τα πεζά. Το «jQuery» έρχεται μετά το «XML».
  • Με collation και locale: "en", η σειρά γίνεται αλφαβητική, ανεξάρτητα από πεζά και κεφαλαία.

MongoDB Manual: Comparison/Sort Order (Collation).

Κείμενο: λέξη ή κομμάτι λέξης

Εντολές

db.books.countDocuments({ title: /Java/ })
db.books.countDocuments({ title: /\bJava\b/ })
db.books.countDocuments({ title: /^Java/ })
db.books.countDocuments({ title: /^Java\b/ })

  • Ζητούμενο 11: το /Java/ βρίσκει 38 τίτλους, μαζί με JavaScript, JavaServer, JavaFX. Μόνο η λέξη Java: \b πριν και μετά, 29.
  • Ζητούμενο 12: το /^Java/ βρίσκει 14. Οι 3 από αυτούς αρχίζουν με JavaServer, JavaFX, JavaScript.
  • Ζητούμενο 13: /^.a.a/, 19 τίτλοι. Η . της regex αντιστοιχεί στο _ του LIKE της SQL.

MongoDB Manual: $regex.

10

Να θυμάστε

Βασικά συμπεράσματα

  1. Η SQL και η MongoDB δια­τυ­πώ­νουν το ίδιο με άλλη σύ­νταξη: το WHERE γί­νε­ται φίλτρο, το SELECT προ­βολή, το ORDER BY sort, το LIMIT limit.
  2. Στην τα­ξι­νό­μηση κει­μέ­νου τα κε­φα­λαία προη­γού­νται των πεζών. Με collation, η σειρά γί­νε­ται αλ­φα­βη­τική.
  3. Το LIKE γί­νε­ται κα­νο­νική έκ­φραση: το 'Java%' γρά­φε­ται /^Java/, το _ γί­νε­ται τελεία, και με \b με­τρούν μόνο ολό­κλη­ρες λέξεις.
