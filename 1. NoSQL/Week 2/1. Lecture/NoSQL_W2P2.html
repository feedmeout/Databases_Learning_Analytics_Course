Ένα λυμένο παράδειγμα

SQL

SELECT title, pageCount FROM books
WHERE status = 'MEAP' AND pageCount > 0
ORDER BY pageCount DESC
LIMIT 3

MongoDB

db.books.find(
  { status: "MEAP", pageCount: { $gt: 0 } },
  { title: 1, pageCount: 1, _id: 0 }
).sort({ pageCount: -1 }).limit(3)

Αποτέλεσμα

[
  { title: 'Groovy in Action, Second Edition', pageCount: 700 },
  { title: 'F# in Action', pageCount: 425 },
  { title: 'Distributed Agile in Action', pageCount: 325 }
]
  • WHERE γίνεται φίλτρο: το AND είναι το κόμμα.
  • SELECT title, pageCount γίνεται προβολή.
  • ORDER BY … DESC γίνεται sort με -1· το LIMIT γίνεται limit.

Java: 96, όχι 76 ούτε 97

Εντολές

db.books.countDocuments({ categories: "Java" })
db.books.countDocuments({ categories: ["Java"] })
db.books.countDocuments({ categories: "java" })
db.books.countDocuments({ categories: { $in: ["Java", "java"] } })

Αποτελέσματα

96
76
1
97
  • Ζητούμενο 4 (πρώτη εντολή): 96 βιβλία.
  • Με αγκύλες, 76: μόνο όσα έχουν ως μοναδική κατηγορία τη Java.
  • Ένα βιβλίο έχει «java» με πεζά. Αν το θέλουμε κι αυτό, $in και τα δύο: 97.

AND ή OR

Εντολές

db.books.countDocuments({ categories: "Java", status: "PUBLISH" })
db.books.countDocuments({ $or: [ { categories: "Java" },
                                 { status: "PUBLISH" } ] })
db.books.countDocuments({ status: "PUBLISH" })
db.books.countDocuments({ categories: "Java", status: "MEAP" })

Αποτελέσματα

95
364
363
1
  • Ζητούμενο 5, AND: 95 βιβλία Java που κυκλοφόρησαν.
  • Ζητούμενο 6, OR: 364, δηλαδή τα 363 που κυκλοφόρησαν και ένα βιβλίο Java σε MEAP.
  • Το «είτε… είτε» της εκφώνησης είναι OR: αρκεί μία από τις δύο συνθήκες.

Ταξινόμηση κειμένου: τα πεζά στο τέλος

Εντολές

db.books.find({ categories: "Java" }, { title: 1, _id: 0 })
  .sort({ title: -1 }).limit(3)
db.books.find({ categories: "Java" }, { title: 1, _id: 0 })
  .sort({ title: -1 }).collation({ locale: "en" }).limit(3)

Αποτελέσματα

[
  { title: 'jQuery in Action, Second Edition' },
  { title: 'iText in Action, Second Edition' },
  { title: 'XML Parsing with Digester' }
]
[
  { title: 'XML Parsing with Digester' },
  { title: 'XDoclet in Action' },
  { title: 'Working with the Logging and Discovery Components' }
]
  • Η MongoDB συγκρίνει τα κείμενα χαρακτήρα προς χαρακτήρα: όλα τα κεφαλαία πριν από τα πεζά. Το «jQuery» έρχεται μετά το «XML».
  • Με collation και locale: "en", η σειρά γίνεται αλφαβητική, ανεξάρτητα από πεζά και κεφαλαία.
  • Ζητούμενο 9: στο τέλος της λίστας είναι τα 19 βιβλία Java με 0 σελίδες.

Να θυμάστε

Τρία σημεία από το Μέρος 2

  1. SQL και MongoDB λένε το ίδιο με άλλη σύνταξη: το WHERE γίνεται φίλτρο, το SELECT προβολή, το ORDER BY sort, το LIMIT limit.
  2. Όπου η SQL θα είχε μία τιμή, η MongoDB μπορεί να έχει λίστα: εκεί η ισότητα σημαίνει «περιέχει».
  3. Τα κείμενα συγκρίνονται χαρακτήρα προς χαρακτήρα: Java, java και JavaScript δίνουν τρία διαφορετικά αποτελέσματα.
