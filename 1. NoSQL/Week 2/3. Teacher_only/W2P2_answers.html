Ζητούμενα 1–3: πλήθος, όλα τα βιβλία, προβολή

1

Το πλήθος των βιβλίων.

db.books.countDocuments()

Με countDocuments(). Το count() λειτουργεί, αλλά με προειδοποίηση απόσυρσης. Πλήθος 0: το mongosh είναι ακόμη στη βάση test, και χρειάζεται use library.

db.books.find()

4

Τα βιβλία της κατηγορίας Java.

db.books.find({ categories: "Java" })

Τα βιβλία της κατηγορίας Java που έχουν κυκλοφορήσει (status PUBLISH).

db.books.find({ categories: "Java", status: "PUBLISH" })

Μόνο ευθέα εισαγωγικά: με τυπογραφικά (“Java”) το mongosh απαντά SyntaxError.

Ζητούμενα 7–9: σελίδες και ταξινόμηση

7

Οι τίτλοι των βιβλίων με περισσότερες από 500 σελίδες.

db.books.find({ pageCount: { $gt: 500 } }, { title: 1, _id: 0 })

Χωρίς _id: 0 εμφανίζεται και το _id.

90έγγραφα
8

Το _id και ο τίτλος των βιβλίων Java, σε αλφαβητική σειρά τίτλου.

db.books.find({ categories: "Java" }, { title: 1 }).sort({ title: 1 })

Πρώτοι τίτλοι: 3D User Interfaces with Java 3D (_id 21), ActiveMQ in Action, Android in Action, Second Edition …

96 έγγραφα. Τα κεφαλαία μπαίνουν πριν από τα πεζά: τα «iText…» και «jQuery…» έρχονται τελευταία. Για αλφαβητική σειρά: .collation({ locale: "en" }).

9

Ο αριθμός σελίδων και ο τίτλος των βιβλίων Java, κατά φθίνουσα σειρά σελίδων.

db.books.find(
  { categories: "Java" }, { pageCount: 1, title: 1, _id: 0 }
).sort({ pageCount: -1 })

Πρώτα: Java Foundation Classes (1088), Swing Second Edition (912), Java Persistence with Hibernate (880) …

Ζητούμενα 10–13: τα πέντε μεγαλύτερα, αναζήτηση σε κείμενο

10

Ο αριθμός σελίδων και ο τίτλος των πέντε βιβλίων με τις περισσότερες σελίδες.

db.books.find(
  {}, { pageCount: 1, title: 1, _id: 0 }
).sort({ pageCount: -1 }).limit(5)

Essential Guide to Peoplesoft Development and Customization (1101), Ten Years of UserFriendly.Org (1096), Java Foundation Classes (1088), Windows Forms in Action (950), Silverlight 5 in Action (925)

5 έγγραφα. Το countDocuments({}) δίνει 431, γιατί δεν λαμβάνει υπόψη το limit.
