Από την SQL στη MongoDB: 13 ζητούμενα στη συλλογή books

Σε ομάδες περίπου τεσσάρων ατόμων, κάθε ομάδα στη δική της αίθουσα του Zoom, για 22 λεπτά, με συντονιστή, που κρατά τον χρόνο, και εισηγητή, που σημειώνει τις απαντήσεις. Ο καθένας εκτελεί τα ερωτήματα στο δικό του mongosh, στη βάση library: use library. Όποιος δεν έχει τη συλλογή, δουλεύει με την οθόνη ενός μέλους της ομάδας.

Για κάθε ζητούμενο γράψτε το ερώτημα της MongoDB και τον αριθμό ελέγχου: στα ζητούμενα 1–7 και 11–13, το πλήθος των εγγράφων, με countDocuments και το ίδιο φίλτρο. Στο 8, το _id του πρώτου βιβλίου της λίστας. Στο 9, οι σελίδες του πρώτου βιβλίου. Στο 10, οι σελίδες του πέμπτου. Στο τέλος, στην κεντρική αίθουσα, ο εισηγητής γράφει στο chat τους 13 αριθμούς, με τη σειρά: «Ομάδα 2: 431, 431, …». Οι ίδιες αντιστοιχίες χρειάζονται στις ενότητες 4 έως 9 της Εργασίας 2.

Βοήθημα: η σελίδα SQL to MongoDB Mapping Chart του εγχειριδίου της MongoDB. Όπου γράφει count(), γράψτε countDocuments(). Στη στήλη SQL, κάθε ζητούμενο είναι διατυπωμένο σαν να είχε κάθε βιβλίο μία μόνο κατηγορία (category). Στη MongoDB το πεδίο λέγεται categories και είναι λίστα: το { categories: "Java" } βρίσκει τα βιβλία με «Java» στη λίστα. Συνοπτικά: AND → κόμμα, { a: 1, b: 2 } · OR → { $or: [ { a: 1 }, { b: 2 } ] } · a > 25 → { a: { $gt: 25 } } · LIKE 'bc%' → /^bc/ · LIKE '%bc%' → /bc/ · SELECT a, b → find({}, { a: 1, b: 1, _id: 0 }) · ORDER BY a → .sort({ a: 1 }), DESC → -1 · LIMIT 5 → .limit(5).
#ΖητούμενοSQLΕρώτημα στη MongoDBΑριθμός ελέγχου
1Το πλήθος των βιβλίων.SELECT COUNT(*) FROM books
2Όλα τα βιβλία.SELECT * FROM books
3Το _id, το status και οι κατηγορίες όλων των βιβλίων.SELECT _id, status, category FROM books
4Τα βιβλία της κατηγορίας Java.SELECT * FROM books WHERE category = 'Java'
5Τα βιβλία της κατηγορίας Java που έχουν κυκλοφορήσει (status PUBLISH).SELECT * FROM books WHERE category = 'Java' AND status = 'PUBLISH'
6Τα βιβλία που ανήκουν στην κατηγορία Java ή έχουν κυκλοφορήσει (ή και τα δύο).SELECT * FROM books WHERE category = 'Java' OR status = 'PUBLISH'
7Οι τίτλοι των βιβλίων με περισσότερες από 500 σελίδες.SELECT title FROM books WHERE pageCount > 500
8Το _id και ο τίτλος των βιβλίων Java, σε αλφαβητική σειρά τίτλου.SELECT _id, title FROM books WHERE category = 'Java' ORDER BY title
9Ο αριθμός σελίδων και ο τίτλος των βιβλίων Java, κατά φθίνουσα σειρά σελίδων.SELECT pageCount, title FROM books WHERE category = 'Java' ORDER BY pageCount DESC
10Ο αριθμός σελίδων και ο τίτλος των πέντε βιβλίων με τις περισσότερες σελίδες.SELECT pageCount, title FROM books ORDER BY pageCount DESC LIMIT 5
11Οι τίτλοι που περιέχουν «Java», ακόμη και ως μέρος λέξης.SELECT title FROM books WHERE title LIKE '%Java%'
12Οι τίτλοι που αρχίζουν από «Java», ακόμη και ως μέρος λέξης.SELECT title FROM books WHERE title LIKE 'Java%'
13Οι τίτλοι με δεύτερο και τέταρτο χαρακτήρα το a.SELECT title FROM books WHERE title LIKE '_a_a%'
