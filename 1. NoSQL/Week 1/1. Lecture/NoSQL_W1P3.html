8

Το πεδίο _id και το ObjectId

12

bytes σε κάθε ObjectId: 4 για τη στιγμή δημιουργίας, 5 τυχαία, 3 μετρητής

Κάθε έγ­γραφο έχει μο­να­δικό _id. Αν δεν το δώ­σουμε, η MongoDB δη­μιουρ­γεί ένα ObjectId.

  • Το _id είναι το πρω­τεύον κλειδί της συλ­λο­γής: μο­να­δικό και αμε­τά­βλητο.
  • Η στιγμή δη­μιουρ­γίας δια­βά­ζε­ται από το ίδιο το ObjectId: .getTimestamp().
  • Μπο­ρούμε να δώ­σουμε δικό μας _id, αρκεί να είναι μο­να­δικό στη συλ­λογή.

MongoDB Manual: ObjectId.

9

Ενσωμάτωση ή αναφορά;

Ενσωμάτωση

  • Τα δε­δο­μένα μπαί­νουν μέσα στο έγ­γραφο (embedding) και δια­βά­ζο­νται μαζί του.
  • Σχέση ένα-προς-λίγα, π.χ. οι διευ­θύν­σεις ενός φοι­τητή.
  • Τα δε­δο­μένα δεν αλ­λά­ζουν ανε­ξάρ­τητα.

Αναφορά

  • Τα δε­δο­μένα αλ­λά­ζουν ή δια­βά­ζο­νται και μόνα τους.
  • Σχέση πολλά-προς-πολλά, ή λίστα χωρίς όριο: ένα έγ­γραφο δεν ξε­περνά τα 16 MB.
  • Το έγ­γραφο κρατά μόνο το _id του άλλου εγ­γρά­φου (reference).

Η από­φαση παίρ­νε­ται ανά σχέση, όχι ανά βάση: μια σχε­δίαση έχει συ­νή­θως και εν­σω­μά­τωση και ανα­φορά.

MongoDB Manual: Data Modeling.

Εισαγωγή ενός εγγράφου: insertOne

Εντολή

db.country.insertOne({
  name: "Greece",
  euSince: 1981,
  population: 10400000
})

Αποτέλεσμα

{
  acknowledged: true,
  insertedId: ObjectId('6ac03b88d126181d95e1c707')
}
  • Στο mongosh τα ονόματα των πεδίων γράφονται και χωρίς εισαγωγικά: name: "Greece".
  • acknowledged: true: ο διακομιστής επιβεβαίωσε την εγγραφή.
  • Το ObjectId στη δική σας οθόνη θα είναι διαφορετικό.

Πληθυσμοί: Eurostat, 1η Ιανουαρίου 2025, στρογγυλοποιημένοι. euSince: έτος ένταξης στην ΕΟΚ/ΕΕ.

Δικό μας _id

Εντολή

db.country.insertOne({
  _id: 2,

Αποτέλεσμα

Εισαγωγή πολλών: insertMany

Εντολή

db.country.insertMany([
  { name: "France", euSince: 1958, population: 68600000,
    capital: { name: "Paris", timezone: "Europe/Paris" } },
  { name: "Germany", euSince: 1958, population: 83600000,
    capital: { name: "Berlin", timezone: "Europe/Berlin" } }

Αποτέλεσμα

{
  acknowledged: true,
  insertedIds: {
    '0': ObjectId('6ac03b88d126181d95e1c708'),
    '1': ObjectId('6ac03b88d126181d95e1c709')
  }
}
  • Μια λίστα εγγράφων σε μία εντολή.
  • Τα δύο νέα έγγραφα έχουν πεδίο capital, που οι δύο πρώτες χώρες δεν έχουν.
  • Ένα _id για κάθε έγγραφο, με τη σειρά εισαγωγής.
  • Παλαιότερα εγχειρίδια γράφουν insert(): λειτουργεί, με προειδοποίηση απόσυρσης.

Η τελεία στα ερωτήματα

Εντολή

db.country.find({ "capital.name": "Paris" })

Αποτέλεσμα

[
  {
    _id: ObjectId('6ac03b88d126181d95e1c708'),
    name: 'France',
    euSince: 1958,
    population: 68600000,
    capital: { name: 'Paris', timezone: 'Europe/Paris' }
  }
]
  • Με την τελεία το ερώτημα μπαίνει μέσα στο εμφωλευμένο έγγραφο.
  • Το όνομα με την τελεία γράφεται πάντα σε εισαγωγικά.
  • Ίδια σύνταξη και για λίστες εγγράφων: "enrolments.course_id".

21

Προσοχή

Η τελεία στο όνομα πεδίου

Εντολές

db.country.insertOne({ name: "Italy", "capital.name": "Rome" })
db.country.findOne({ name: "Italy" })
db.country.deleteOne({ name: "Italy" })

Αποτελέσματα του findOne και του deleteOne

{
  _id: ObjectId('6ac03b88d126181d95e1c70b'),
  name: 'Italy',
  'capital.name': 'Rome'
}
{ acknowledged: true, deletedCount: 1 }
  • Με τελεία στο όνομα, η εισαγωγή δημιουργεί ένα πεδίο με όνομα «capital.name», όχι εμφωλευμένο έγγραφο.
  • Το find({ "capital.name": "Rome" }) δεν επιστρέφει τίποτε: στα ερωτήματα η τελεία σημαίνει διαδρομή.
  • Σωστά: capital: { name: "Rome" }. Το deleteOne αφαιρεί το λανθασμένο έγγραφο.

Να θυμάστε

Βασικά συμπεράσματα

  1. Βάση, συλ­λογή, έγ­γραφο: η MongoDB απο­θη­κεύει έγ­γραφα BSON, καθένα με μο­να­δικό _id.
  2. Η από­φαση παίρ­νε­ται ανά σχέση: εν­σω­μα­τώ­νε­ται ό,τι ανήκει στο έγ­γραφο, και με ανα­φορά μπαί­νει ό,τι αλ­λά­ζει ανε­ξάρ­τητα ή με­γα­λώ­νει χωρίς όριο.
  3. Στα ερω­τή­ματα, η τελεία οδηγεί μέσα στο εμ­φω­λευ­μένο έγ­γραφο. Στην ει­σα­γωγή, γρά­φουμε έγ­γραφο μέσα σε έγ­γραφο.
