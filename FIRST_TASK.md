1. Unzip this into the top level of your course folder (CLAUDE.md must sit at the top).
2. In that folder: `git init`, `git add .`, `git commit -m "Course material, build kit v13"`, then push it to a new PRIVATE GitHub repository.
3. Open Claude Code (claude.ai/code), connect the repository, and paste the message below.
