2

matchedCount και modifiedCount

Η ίδια εντολή, δεύτερη φορά

db.country.updateOne(
  { name: "Greece" },
  { $set: { capital: { name: "Athens", timezone: "Europe/Athens" } } }
)

Αποτέλεσμα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 0,
  upsertedCount: 0
}
  • Βρέθηκε ένα έγγραφο (matchedCount: 1), αλλά δεν άλλαξε (modifiedCount: 0): η τιμή ήταν ήδη αυτή.
  • Με matchedCount: 0, το φίλτρο δεν βρήκε τίποτε: π.χ. "greece" με πεζό.

3

$inc και $push

Εντολές

db.country.updateOne(
  { name: "Greece" },
  { $inc: { visits: 1 }, $push: { languages: "Greek" } }
)
db.country.findOne({ name: "Greece" }, { _id: 0 })

Αποτελέσματα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
{
  name: 'Greece',
  euSince: 1981,
  population: 10400000,
  capital: { name: 'Athens', timezone: 'Europe/Athens' },
  languages: [ 'Greek' ],
  visits: 1
}
  • $inc: αυξάνει έναν αριθμό· αν το πεδίο λείπει, το δημιουργεί.
  • $push: προσθέτει στοιχείο σε λίστα· αν η λίστα λείπει, τη δημιουργεί.
  • Δύο τελεστές στην ίδια ενημέρωση.

MongoDB Manual: Field and Array Update Operators.

Εντολή

Προσοχή

updateOne: μόνο το πρώτο έγγραφο

Εντολές

db.country.updateOne({ euSince: 1958 }, { $set: { founder: true } })
db.country.countDocuments({ founder: true })
db.country.updateMany({ euSince: 1958 }, { $set: { founder: true } })

Αποτελέσματα

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
1
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 2,
  modifiedCount: 1,
  upsertedCount: 0
}
  • Γαλλία και Γερμανία έχουν euSince 1958· το updateOne άλλαξε μόνο την πρώτη.
  • Το updateMany βρήκε και τις δύο (matchedCount: 2) και άλλαξε όποια δεν είχε ήδη την τιμή (modifiedCount: 1).

db.books.countDocuments({ pageCount: { $exists: false } })

switched to db library
{
  acknowledged: true,

  • Ένα φίλτρο, πολλά έγγραφα: και τα 166 βιβλία με 0 σελίδες.

upsert: η Κύπρος επιστρέφει

Εντολές

use world
db.country.updateOne(
  { name: "Cyprus" },
  { $set: { population: 980000 } },
  { upsert: true }
)
db.country.findOne({ name: "Cyprus" }, { _id: 0 })

Αποτελέσματα

switched to db world
{
  acknowledged: true,
  insertedId: ObjectId('6ab42c38413cb46e99da303c'),
  matchedCount: 0,
  modifiedCount: 0,
  upsertedCount: 1
}
{ name: 'Cyprus', population: 980000 }
  • Κανένα έγγραφο δεν ταίριαξε: με upsert: true δημιουργείται νέο.
  • Το νέο έγγραφο παίρνει το name από το φίλτρο και το population από το $set.

$group: ο συνολικός πληθυσμός

Εντολή

db.country.aggregate([
  { $group: { _id: null, totalPopulation: { $sum: "$population" } } }
])

Αποτέλεσμα

[ { _id: null, totalPopulation: 162600000 } ]
  • _id: null: μία μόνο ομάδα, όλα τα έγγραφα μαζί.
  • "$population": η τιμή του πεδίου· το $ μπροστά από το όνομα.
  • Ελλάδα, Γαλλία και Γερμανία: 162.600.000.

MongoDB Manual: $group (aggregation).

16

$match και υπολογισμοί ανά ομάδα

Εντολή

db.books.aggregate([
  { $match: { categories: "Java" } },
  { $group: { _id: "$status", books: { $sum: 1 },
              avgPages: { $avg: "$pageCount" },
              maxPages: { $max: "$pageCount" } } }
])

Αποτέλεσμα

[
  { _id: 'MEAP', books: 1, avgPages: 700, maxPages: 700 },
  {
    _id: 'PUBLISH',
    books: 95,
    avgPages: 511.4868421052632,
    maxPages: 1088
  }
]
  • $match πρώτο: μόνο τα βιβλία Java, όπως το WHERE.
  • $avg και $max: μέσος όρος και μέγιστο ανά ομάδα.
  • Το $avg αγνοεί τα βιβλία που δεν έχουν πλέον pageCount (διαφάνεια 8).

MongoDB Manual: $avg (aggregation).

17

$unwind: ένα έγγραφο ανά κατηγορία

Εντολή

db.books.aggregate([
  { $unwind: "$categories" },
  { $group: { _id: "$categories", books: { $sum: 1 } } },
  { $sort: { books: -1 } },
  { $limit: 5 }
])

Αποτέλεσμα

[
  { _id: 'Java', books: 96 },
  { _id: 'Internet', books: 41 },
  { _id: 'Microsoft .NET', books: 34 },
  { _id: 'Web Development', books: 17 },
  { _id: 'Software Engineering', books: 16 }
]
  • $unwind: ένα έγγραφο για κάθε κατηγορία κάθε βιβλίου.
  • Μετά: ομάδα ανά κατηγορία, ταξινόμηση, τα πέντε πρώτα.
  • Βιβλία χωρίς κατηγορία δεν περνούν από το $unwind.

MongoDB Manual: $unwind (aggregation).

18

$match μετά το $group: το HAVING

Εντολή

db.books.aggregate([
  { $unwind: "$categories" },
  { $group: { _id: "$categories", books: { $sum: 1 } } },
  { $match: { books: { $gte: 12 } } },
  { $sort: { books: -1, _id: 1 } }
])

Αποτέλεσμα

[
  { _id: 'Java', books: 96 },
  { _id: 'Internet', books: 41 },
  { _id: 'Microsoft .NET', books: 34 },
  { _id: 'Web Development', books: 17 },
  { _id: 'Software Engineering', books: 16 },
  { _id: 'Business', books: 12 },
  { _id: 'Programming', books: 12 }
]
  • $match μετά το $group φιλτράρει ομάδες, όπως το HAVING της SQL.
  • Κατηγορίες με τουλάχιστον 12 βιβλία: επτά.
  • _id: 1 στο $sort: σταθερή σειρά στις ισοπαλίες.

19

$project: το σχήμα της εξόδου

Εντολή

db.books.aggregate([
  { $match: { categories: "Java" } },
  { $group: { _id: "$status", books: { $sum: 1 },
              avgPages: { $avg: "$pageCount" } } },
  { $project: { _id: 0, status: "$_id", books: 1,
                avgPages: { $round: ["$avgPages", 0] } } }
])

Αποτέλεσμα

[
  { books: 1, status: 'MEAP', avgPages: 700 },
  { books: 95, status: 'PUBLISH', avgPages: 511 }
]
  • $project: ποια πεδία βγαίνουν και με ποιο όνομα· το _id γίνεται status.
  • $round: στρογγυλοποίηση του μέσου όρου.
  • Το $project αντιστοιχεί στο SELECT της SQL.

MongoDB Manual: $project· $round (aggregation).

SQL και MongoDB: εντολές

SQLMongoDB
INSERT INTO … VALUES …insertOne, insertMany
SELECT … FROM … WHERE …find(φίλτρο, προβολή)
UPDATE … SET … WHERE …updateOne, updateMany με $set
SET age = age + 3$inc: { age: 3 }
DELETE FROM … WHERE …deleteOne, deleteMany με φίλτρο
DELETE FROM peopledeleteMany({})
ALTER TABLE … ADD …updateMany({}, { $set: … })
ALTER TABLE … DROP COLUMN …updateMany({}, { $unset: … })

Στη MongoDB δεν υπάρχει ALTER TABLE: η συλλογή δεν επιβάλλει δομή, και τα πεδία αλλάζουν στο επίπεδο του εγγράφου.

  2. Η συνάθροιση είναι ροή σταδίων: το $match φιλτράρει, το $group ομαδοποιεί, τα $sort, $limit και $project διαμορφώνουν την έξοδο.
  3. Πριν από κάθε μαζική αλλαγή ή διαγραφή, countDocuments με το ίδιο φίλτρο.
